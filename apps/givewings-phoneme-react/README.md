# GiveWings dashboard — PHONEME palette

React + Vite implementation of the dashboard concept, using black, #FF7200, and white as the primary palette.

## Run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. `npm run build` creates a production bundle in `dist/`.

The page is a front-end demo. Product additions, filters, search, modal details, navigation and notifications work in the browser; data is kept in localStorage. AI actions and backend integration are represented as demo interactions.
